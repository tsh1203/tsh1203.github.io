## 题意
给定**代价数组**，求通过**最多一次免费交换**和多次**字母变换**（代价），将字符串  变为**回文串**的**最小总代价**。

## 思路

首先我们定义 $f_{i,j}$ 为令 $S_i=S_j$ 的最小代价。

很显然，我们可以用以下代码求解：

```cpp
if(s[l]!=s[r])f[i][j]=min(v[s[l]-'a'+1],min(v[s[r]-'a'+1],mi*2));
else f[i][j]=0;
```

将 $S$ 变为回文串的最小代价为：

$$
\sum_{i = 0}^{\frac{n}{2}-1} f[i][n-i-1]
$$

$O(n^3)$ 思路很显然，我们直接跳过。

简单优化后可以写出 $O(n^2)$ 暴力。

先计算出原始代价，然后 $O(n^2)$ 遍历交换再求出交换后的代价取最小值即可。

```cpp
#include<bits/stdc++.h>
//#pragma GCC optimize("3","inline") 
#define int long long
#ifdef __linux__
#define getchar getchar_unlocked
#define putchar putchar_unlocked
#else
#define getchar _getchar_nolock
#define putchar _putchar_nolock
#endif
using namespace std;
namespace FastIO {
	void read(){}
	template <class T1,class ... T2> inline void read(T1 &x,T2 &... oth){
		bool pd=0;x=0;char ch=getchar();
		while(!isdigit(ch)){pd|=ch=='-';ch=getchar();}
		while(isdigit(ch)){x=(x<<3)+(x<<1)+(ch^48);ch=getchar();}
		x=pd?-x:x;
		read(oth...);
	}
	template <class T> void _write(T x){
		if(x<0){putchar('-');x=-x;}
		if(x>9) _write(x/10);
		putchar(x%10^48);
	}
	void write(){}
	template <class T1,class ... T2>
	inline void write(T1 x,T2 ...oth){_write(x);putchar(' ');write(oth...);}
	inline void endline(){putchar('\n');}
}//Orz lby 
using namespace FastIO;
int n;
int v[30],mi=1e12,cnt,ans=1e18;
string s;
int upd(int l,int r){
	if(s[l]!=s[r])return min(v[s[l]-'a'+1],min(v[s[r]-'a'+1],mi*2));
	return 0;
}
signed main(){
//	freopen(".in","r",stdin); 
//	freopen(".out","w",stdout); 
	read(n);
	for(int i=1;i<=26;i++){
		read(v[i]);
		mi=min(mi,v[i]);
	}
	cin>>s;
	int l=0,r=n-1;
	while(l<r){
		cnt+=upd(l,r);
		l++,r--;
	}
	ans=cnt;
	for(int i=0;i<n-1;i++){
		for(int j=i+1;j<n;j++){
			int lst=cnt;
			cnt-=upd(i,n-1-i);
			cnt-=upd(j,n-1-j);
			swap(s[i],s[j]);
			cnt+=upd(i,n-1-i);
			cnt+=upd(j,n-1-j);
			ans=min(ans,cnt);
			swap(s[j],s[i]);
			cnt=lst;
		}
	}
	write(ans);
	return 0;
}
```

很显然只能拿 60pt。

考虑优化。

[zrt](https://www.luogu.com.cn/user/1270651) 大佬首先想到了随机化，对于 $n>10^4$ 的情况单独用随机化求交换的点。

数据太水了，于是我们可以轻松通过（甚至跑得飞快）。

因为是随机化，不分析时间复杂度。

```cpp
#include<bits/stdc++.h>
#pragma GCC optimize("Ofast","inline") 
#define int long long
using namespace std;
mt19937 rnd(233);
int n;
int v[30],mi=1e12,cnt,ans=1e18;
string s;
int minn(int a,int b){
	return a<b?a:b; 
}
int upd(int l,int r){
	if(__builtin_expect(s[l]!=s[r],1))return minn(v[s[l]-'a'],minn(v[s[r]-'a'],mi<<1));
	return 0;
}
signed main(){
//	freopen(".in","r",stdin); 
//	freopen(".out","w",stdout); 
	ios::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);
	cin>>n;
	for(int i=0;i<26;i++){
		cin>>v[i];
		mi=minn(mi,v[i]);
	}
	cin>>s;
	int l=0,r=n-1,lst;
	while(l<r){
		cnt+=upd(l,r);
		l++,r--;
	}
	ans=cnt;
	if(n>10000){
		for(int i=0;i<n-1;i++){
			int tot=0;
			for(int k=1;k*n<1500000;k++){
				if(tot>n)break;
				tot++;
				int j=rnd()%n+1;
				if(__builtin_expect(s[i]==s[j]||j==n-i-1,0))continue;
				lst=cnt;
				cnt-=upd(i,n-1-i);
				cnt-=upd(j,n-1-j);
				swap(s[i],s[j]);
				cnt+=upd(i,n-1-i);
				cnt+=upd(j,n-1-j);
				ans=minn(ans,cnt);
				swap(s[j],s[i]);
				cnt=lst;
			}
		}
	}
	else{
		for(int i=0;i<n-1;i++){
			for(int j=i+1;j<n;j++){
				if(__builtin_expect(s[i]==s[j]||j==n-i-1,0))continue;
				lst=cnt;
				cnt-=upd(i,n-1-i);
				cnt-=upd(j,n-1-j);
				swap(s[i],s[j]);
				cnt+=upd(i,n-1-i);
				cnt+=upd(j,n-1-j);
				ans=minn(ans,cnt);
				swap(s[j],s[i]);
				cnt=lst;
			}
		}	
	}
	cout<<ans;
	return 0;
}
```
