kosaraju 算法 ​

求强连通分量，理解难度严格小于 tarjan，核心建反图正反各跑一次 dfs，第二次根据第一次的后序遍历倒过来跑。

cpp
void dfs(int u){
	vis[u]=1;
	for(int v:e[u]){
		if(!vis[v])dfs(v);
	}
	q[++cnt]=u;
}
void dfs2(int u){
	f[u]=cnt;
	for(int v:g[u]){
		if(!f[v])dfs2(v);
	}
}
void scc(){
	for(int i=1;i<=2*n;i++){
		if(!vis[i])dfs(i);
	}
	cnt=0;
	for(int i=2*n;i>0;i--){
		if(!f[q[i]]){
			cnt++;
			dfs2(q[i]);
		}
	}
}

2-SAT ​

给定多个布尔变量，以及形如 (A∨B)（即 A 或 B 至少有一个为真）的限制条件，求是否存在可行方案或直接求出可行方案。

考虑转化为图论，A′ 表示 A 为假，边 A→B 表示若 A 为真，则 B 为真；A′→B 表示若 A 为假，则 B 为真。

建边方式可参考下面的表格。

限制条件含义对应建边
A∨B（A 或 B 至少一个为真）A 或 B 至少一个为真A′→B B′→A
¬(A∧B)A 和 B 不能同时为真A→B′ B→A′
AA 必须为真A′→A
(A⟺B)A 和 B 必须相同A→B B→A A′→B′ B′→A′

建图时建正反两个图，跑 kosaraju/trojan 求 SCC，在同一个强连通分量内，若有一个命题成立（可以是逆命题），则该分量内所有命题都成立。如果存在一组 A 与 A‘ 处在同一个强连通分量内，则一定不存在解，若不存在则一定有解。

此处我选择的是 kosaraju，先跑正图再跑反图，记录 SCC 的编号，输出可行情况时比较 A 和 A′ 的强连通分量编号并取较大的一个，证明可参考这篇题解。

Day 3 ​

单调队列优化 DP ​

对于这样的一个 DP 转移（li 单调不降）。

dpi=maxj∈[li,i−1]{dpj+Aj+Bi}

暴力显然 O(n2)，不展开叙述。

注意到 Bi 是常量，我们可以把，Bi 从 max 里提出来，得到

dpi=maxj∈[li,i−1]{dpj+Aj}+Bi

时间复杂度的瓶颈在于暴力求 maxj∈[li,i−1]{dpj+Aj}，因为 li 单调不降，所以我们可以考虑滑动窗口的方式维护，所以单调队列维护即可，O(n)，当然，数据范围比较小的情况下你写线段树也是可以的。

f[i]=minj∈[i−2B,i−2A]{f[j]}+1

斜率优化 ​

没听懂。

大体应该就是将一个类似于上面单调队列的 DP 式子拆分后化为 y=kx+b 的形式，只跟 j 有关的项看作因变量 y，跟 i,j 相关的乘积项看作斜率乘自变量 kx，其中 k 即斜率只与决策点 i 有关，把方程中跟 j 相关的项移到等号左边，其余移到右边，再用单调队列维护凸包。

P3628 ​

细节很多的一道题。

容易写出暴力转移方程

f[i]=max0≤j<i{f[j]+a(Si−Sj)2+b(Si−Sj)+c}

展开得到：

f[i]=f[j]+aSi2−2aSiSj+aSj2+bSi−bSj+c

按照直线方程进行映射。

yj=f[j]+aSj2−bSj

xj=S[j]

ki=2a⋅s[i]

因为 a<0，s[i] 单调递增，所以 ki 单调递减，为了使截距最大化，我们维护一个上凸包，然后就是板子了。

Day 5 ​

字符串 ​

注：因为老师没讲完，可在这里查看讲义

基础定义 ​

S：表示一个字符串（通常由 26 个小写字母组成）。

|S|：表示字符串的长度。

S[i]：表示字符串第 i 个位置的字母（下标从 1 开始）。

S[l,r]：表示从第 l 到第 r 个字母顺次连接而成的子串。

pre[i]：长度为 i 的前缀，即 S[1,i]。

suf[i]：长度为 i 的后缀，即 S[n−i+1,n]。

Border & 周期 ​

如果一个字符串的同长度前缀和后缀完全相同，即 pre[i]=suf[i]，则称此前缀（或后缀）为一个 Border。

若满足 S[i]=S[i−p]（对于所有 p<i≤n 成立），则称 p 为 S 的一个周期 。

性质 ​

  1. p 是 S 的周期 ⟺ n - p 是 S 的 Border 长

  2. 传递性
    结论：S 的 Border 的 Border 也是 S 的 Border 。
    推论：求 S 的所有 Border 等价于求所有前缀的最大 Border 。

KMP ​

nxt[i]：前缀 pre[i] 的非平凡最大 Border 长度，nxt[1]=0。

即不包含前缀 pre[i] 本身的最大 Border。

求 nxt[i] 时，如果 S[i]!=S[nxt[i−1]+1]，则需要沿着 nxt 指针回溯：遍历 nxt[i−1],nxt[nxt[i−1]], …, 0，直到找到匹配的字符 。
