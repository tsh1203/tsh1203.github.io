## kosaraju 算法

求强连通分量，理解难度严格小于 tarjan，核心建反图正反各跑一次 dfs，第二次根据第一次的后序遍历倒过来跑。

```cpp
void dfs(int u){
	vis[u]=1;
	for(int v:e[u]){
		if(!vis[v])dfs(v);
	}
	q[++cnt]=u;
}
void dfs2(int u){
	f[u]=cnt;
	for(int v:g[u]){
		if(!f[v])dfs2(v);
	}
}
void scc(){
	for(int i=1;i<=2*n;i++){
		if(!vis[i])dfs(i);
	}
	cnt=0;
	for(int i=2*n;i>0;i--){
		if(!f[q[i]]){
			cnt++;
			dfs2(q[i]);
		}
	}
}
```

## 2-SAT

给定多个布尔变量，以及形如 $(A \lor B)$（即 $A$ 或 $B$ 至少有一个为真）的限制条件，求是否存在可行方案或直接求出可行方案。

考虑转化为图论，$A'$ 表示 $A$ 为假，边 $A\to B$ 表示若 $A$ 为真，则 $B$ 为真；$A' \to B$ 表示若 $A$ 为假，则 $B$ 为真。

建边方式可参考下面的表格。

| 限制条件 | 含义  | 对应建边 |
|:----:|:---:|:----:|
| $A \lor B$（$A$ 或 $B$ 至少一个为真） | $A$ 或 $B$ 至少一个为真 | $A' \to B$  $B' \to A$ |
| $\neg(A \land B)$ | $A$ 和 $B$ 不能同时为真 | $A \to B'$ $B \to A'$ |
| $A$  | $A$ 必须为真 | $A' \to A$ |
| $(A \iff B)$ | $A$ 和 $B$ 必须相同 | $A \to B$  $B \to A$  $A' \to B'$  $B' \to A'$ |

建图时建正反两个图，跑  kosaraju/trojan 求 SCC，在同一个强连通分量内，若有一个命题成立（可以是逆命题），则该分量内所有命题都成立。如果存在一组 $A$ 与 $A`$ 处在同一个强连通分量内，则一定不存在解，若不存在则一定有解。

此处我选择的是 kosaraju，先跑正图再跑反图，记录 SCC 的编号，输出可行情况时比较 $A$ 和 $A'$ 的强连通分量编号并取较大的一个，证明可参考[这篇题解](https://www.luogu.com.cn/article/r5qofj1n)。

## 单调队列优化 DP

对于这样的一个 DP 转移（$l_i$ 单调不降）。

$$
dp_i = \max_{j \in [l_i, i-1]} \{ dp_j + A_j + B_i\} 
$$

暴力显然 $O(n^2)$，不展开叙述。

注意到 $B_i$ 是常量，我们可以把，$B_i$ 从 max 里提出来，得到

$$
dp_i = \max_{j \in [l_i, i-1]} \{ dp_j + A_j \} + B_i
$$

时间复杂度的瓶颈在于暴力求 $\max_{j \in [l_i, i-1]} \{ dp_j + A_j \}$，因为 $l_i$ 单调不降，所以我们可以考虑滑动窗口的方式维护，所以单调队列维护即可，$O(n)$，当然，数据范围比较小的情况下你写线段树也是可以的。

## 斜率优化
没完全听懂。

大体应该就是将一个类似于上面单调队列的 DP 式子拆分后化为 $y=kx+b$ 的形式，只跟 $j$ 有关的项看作因变量 $y$，跟 $i,j$ 相关的乘积项看作斜率乘自变量 $kx$，其中 $k$ 即斜率只与决策点 $i$ 有关，把方程中跟 $j$ 相关的项移到等号左边，其余移到右边，再用单调队列维护凸包。

### P2365
题目疑似有点歧义，可以去看下题，$t,f$ 为前缀和。

$$dp[i] = \min_{0 \le j < i}\{ dp[j] + t[i] \cdot (f[i] - f[j]) + s \cdot (f[n] - f[j]) \}$$

前缀和优化到 $O(n^2)$。

### P3628
细节很多的一道题。

容易写出暴力转移方程

$$f[i] = \max_{0 \le j < i} \{ f[j] + a(S_i - S_j)^2 + b(S_i - S_j) + c \}$$

展开得到：

$$f[i] = f[j] + aS_i^2 - 2aS_iS_j + aS_j^2 + bS_i - bS_j + c$$

按照直线方程进行映射。

$y_j = f[j] + aS_j^2 - bS_j$

$x_j=S[j]$

$k_i=2a\cdot s[i]$

因为 $a<0$，$s[i]$ 单调递增，所以 $k_i$ 单调递减，为了使截距最大化，我们维护一个上凸包，然后就是板子了。
