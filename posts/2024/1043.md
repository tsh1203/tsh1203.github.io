## kosaraju 算法

求强连通分量，理解难度严格小于 tarjan，核心建反图正反各跑一次 dfs，第二次根据第一次的后序遍历倒过来跑。

```cpp
void dfs(int u){
	vis[u]=1;
	for(int v:e[u]){
		if(!vis[v])dfs(v);
	}
	q[++cnt]=u;
}
void dfs2(int u){
	f[u]=cnt;
	for(int v:g[u]){
		if(!f[v])dfs2(v);
	}
}
void scc(){
	for(int i=1;i<=2*n;i++){
		if(!vis[i])dfs(i);
	}
	cnt=0;
	for(int i=2*n;i>0;i--){
		if(!f[q[i]]){
			cnt++;
			dfs2(q[i]);
		}
	}
}
```

## 2-SAT

给定多个布尔变量，以及形如 $(A \lor B)$（即 $A$ 或 $B$ 至少有一个为真）的限制条件，求是否存在可行方案或直接求出可行方案。

考虑转化为图论，$A'$ 表示 $A$ 为假，边 $A\to B$ 表示若 $A$ 为真，则 $B$ 为真；$A' \to B$ 表示若 $A$ 为假，则 $B$ 为真。

建边方式可参考下面的表格。

| 限制条件 | 含义  | 对应建边 |
|:----:|:---:|:----:|
| $A \lor B$（$A$ 或 $B$ 至少一个为真） | $A$ 或 $B$ 至少一个为真 | $A' \to B$  $B' \to A$ |
| $\neg(A \land B)$ | $A$ 和 $B$ 不能同时为真 | $A \to B'$ $B \to A'$ |
| $A$  | $A$ 必须为真 | $A' \to A$ |
| $(A \iff B)$ | $A$ 和 $B$ 必须相同 | $A \to B$  $B \to A$  $A' \to B'$  $B' \to A'$ |

建图时建正反两个图，跑  kosaraju/trojan 求 SCC，在同一个强连通分量内，若有一个命题成立（可以是逆命题），则该分量内所有命题都成立。如果存在一组 $A$ 与 $A`$ 处在同一个强连通分量内，则一定不存在解，若不存在则一定有解。

此处我选择的是 kosaraju，先跑正图再跑反图，记录 SCC 的编号，输出可行情况时比较 $A$ 和 $A'$ 的强连通分量编号并取较大的一个，证明可参考[这篇题解](https://www.luogu.com.cn/article/r5qofj1n)。
